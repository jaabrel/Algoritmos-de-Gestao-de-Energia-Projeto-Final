# FlySim-RL

**FlySim-RL** é um simulador computacional desenvolvido em Python para o treino, avaliação e validação de algoritmos de Aprendizagem por Reforço (*Reinforcement Learning* - RL) aplicados à exploração e mapeamento de plumas de poluição em ambientes marinhos.

Este projeto foi desenvolvido no âmbito académico no **Politécnico de Tomar (Instituto Politécnico de Tomar)** por **João Alexandre de Abreu** e **Rodrigo Mendes Pinheiro**.

## Instalação e Requisitos

**Python 3.8+**

```bash
pip install numpy numba opencv-python h5py gymnasium matplotlib
```

## Execução:

```bash
python main.py
```
